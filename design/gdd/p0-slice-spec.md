# P0 可玩验证版规格

> 版本:v0.1
> 对应:`design/gdd/game-design-document.md` v0.3 §6.1 的 P0 阶段
> 目的:用最小内容回答四个问题——战斗爽不爽、维修段无不无聊、呼吸决策能不能吵起来、失控友军好不好笑
> 所有数值均为**首版提案**,按 §8 的顺序调,不要一次全改

---

## 1. 范围

### 做

- 2 人直连联机
- 2 角色:吞噬细胞、调节 T 细胞
- 1 张灰盒血管关卡
- 2 个交战段 + 2 个维修段
- 1 类敌人:高炎症型病毒
- 账单、炎症区、免疫风暴、倒地救援、健康值、战报

### 不做

- 血小板、破口、维修材料、残毒
- 快速变异型 / 潜伏型 / 隐身型
- 细胞因子卡
- 3 人局、多器官、装备与成长
- 正式美术与配音

## 2. 一局流程

| 阶段 | 目标时长 | 内容 |
|---|---|---|
| 配队 | 30s | 两人分别确认角色(吞噬细胞 + 调节 T 细胞) |
| 进入 | 30s | 沿血管滑行,看到器官旧伤 |
| 交战 1 | 90–120s | 10 只高炎症型,分 3 批 |
| 维修 1 | 40–70s | 4 个炎症区 |
| 呼吸决策 1 | ≤10s | 修完再走 / 提前跳波 |
| 交战 2 | 90–120s | 14 只,分 3 批 |
| 维修 2(大修) | 50–80s | 5 个炎症区;修完即通关 |
| 结算 | 15s | 战报 |

总计约 6–9 分钟。若偏短,拉长敌人批次间隔,**不要加新内容**。

| 持续 | 20s |
| 血量 | 150 |
| 移速 | 3.0 m/s |
| 攻击 | 10 伤害/秒,攻击最近的任何目标(不分敌我) |
| 索敌半径 | 12m |

### 3.7 一局的账(先把账算一遍)

- 波 1 债务:10 × 16 = **160** → 4 个炎症区
- 维修 1 净速:调节 T 8/s + 吞噬 4/s ≈ 12 债务/秒 → 清空约 15–20s,加跑位共 40–60s
- 波 2 再加 14 × 16 = **224**;若维修 1 已清空,则 224/50 = 4.5 → **5 个炎症区**
- 健康损耗:维修段里平均 2–3 个区在烧,40s 约掉 80–120(8–12%)
- 两波总计预期掉 **20–30%** 健康

## 4. 目标节奏(调参判据)

| 指标 | 目标 | 不达标怎么办 |
|---|---|---|
| 交战段 | 90–120s | 短了:拉长批次间隔或增加批数;长了:降敌人血量 |
| 维修段 | 40–70s | 短了:加每区债务或降净化速度;长了:反过来 |
| 每局健康损耗 | 20–35% | 高了:降炎症区伤害;低了:提高 |
| 呼吸分歧 | 每局 ≥1 次 | 说明债务压力不够,提高波 2 债务 |
| 风暴观感 | 玩家会笑,且有人喊指令 | 不笑:减到 2 只;太乱:缩短到 15s |

## 5. 关卡布局

### 5.1 布局规则

1. **三个维修节点**,保证 2 人必须分头:炎症区随机分布在至少 2 个节点。
2. 每个节点最多 3 个炎症区,不允许扎堆。
3. 增援口与维修节点距离 ≥2 个移动段,维修时不被持续打断。
4. 维修节点之间**视线不互通**,逼出"我这边还剩一个"的沟通。
5. 全图单程跑动 ≤15s,来回 ≤30s。
6. 交战厅 ≥25m × 20m,能容纳 10 只敌人和 2 名玩家走位。

### 5.2 灰盒平面图

```
                [S1 增援口]
                     |
   [A 入口厅] ---- [B 主交战厅] ---- [C 侧厅]
        |                |               |
   [D 维修节点]     [E 核心]        [S2 增援口]
```

- A / B / C 为交战与维修共用区;D / E 为维修延伸区
- S1 / S2:敌人增援口,每波从随机一个口出
- E 核心:大修段的器官核心,也是健康值 HUD 的可视化锚点

### 5.3 元素表

| 元素 | 数量 | 尺寸 | 用途 |
|---|---|---|---|
| 增援口 | 2 | 3m 宽 | 敌人入场 |
| 维修节点 | 3 | 直径 10m | 炎症区生成 |
| 走廊 | 3 | 4m 宽 | 跑位与视线阻断 |
| 掩体 | 8–12 | 1–2m | 走位与阻断 |
| 核心 | 1 | 半径 6m | 大修段锚点 |

- [ ] 2 人直连进同一局

## 8. 调参顺序

1. **打击手感**:50 DPS / 120 血 / 受击反馈。判据:单人连续击杀 5 只不觉得拖。
2. **账单比例**:击杀债务 vs 净化速度。判据:维修段落在 40–70s。
3. **健康流失**:炎症区伤害。判据:两波掉 20–35%。
4. **风暴**:数量、时长、阈值。判据:玩家会笑,且不打断节奏。
5. 最后才碰关卡尺寸。

**一次只改一个变量**,改完记录到简报或本文件的版本备注里。

## 9. 已知风险

| 风险 | 表现 | 处理 |
|---|---|---|
| 维修段变跑步 | 40% 时间在跑 | 缩短节点间距,砍掉一个节点 |
| 账单不可读 | 玩家说不清欠多少 | HUD 用"欠账"单位并显示数字 |
| 风暴变噪音 | 只在添乱 | 减到 2 只,延长触发间隔 |
| 交战太长 | 疲劳 | 降敌人血量,不加数量 |
| 吞噬在维修段没事干 | 玩家站着看 | 增加清创数量,或让协助净化更划算 |
